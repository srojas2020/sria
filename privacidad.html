Política de Privacidad — MCP - Gmail

Última actualización: 21 de agosto de 2026

1. Qué es esta aplicación

MCP - Gmail es una herramienta personal desarrollada por Sergio Germán Rojas (SR.IA) para gestionar su propia casilla de correo electrónico desde su computadora, mediante la API de Gmail de Google.

No es un producto comercial, no se ofrece al público y no tiene usuarios registrados más allá de su propio autor.

2. Quién la usa

La aplicación es utilizada exclusivamente por su desarrollador y propietario, sobre su propia cuenta de Google (sergiorojas001@gmail.com). No accede a casillas de terceros ni permite que terceros accedan a datos a través de ella.

3. Qué datos accede

La aplicación solicita el permiso gmail.modify de la API de Gmail. Ese permiso le habilita a:

AcciónPara qué
Leer mensajes y conversacionesConsultar correos recibidos y su contenido
Buscar en la casillaLocalizar mensajes por remitente, asunto o fecha
Redactar borradoresPreparar correos antes de enviarlos
Enviar y responder correosComunicación habitual del propietario
Gestionar etiquetas y estado de lecturaOrganizar la casilla
Mover mensajes a la papeleraDepurar la casilla

La aplicación no accede a contactos, calendario, archivos de Drive ni a ningún otro servicio de Google.

4. Para qué se usan los datos

Únicamente para que el propietario opere su propia casilla de correo: leer, buscar, redactar, responder, enviar y organizar mensajes.

Los datos no se usan para publicidad, no se venden, no se ceden y no se emplean para entrenar modelos de inteligencia artificial.

5. Dónde se guardan los datos

La aplicación no tiene servidores propios ni base de datos. Se ejecuta localmente en la computadora del propietario.

  • Las credenciales de acceso (token de OAuth) se guardan únicamente en el disco local de esa computadora.
  • El contenido de los correos no se almacena: se consulta a la API de Gmail en el momento y se descarta al terminar la operación.
  • No se genera ninguna copia ni respaldo del contenido de la casilla.

6. Con quién se comparten los datos

Con nadie, con una única salvedad que se declara con transparencia:

La herramienta se opera a través de un asistente de inteligencia artificial (Claude, de Anthropic). Cuando el propietario le pide leer o redactar un correo, el contenido involucrado en esa operación se procesa mediante la API de Anthropic para poder generar la respuesta.

Se trata siempre de correos de la casilla del propio propietario, operados por él mismo y a pedido expreso suyo. No hay datos de terceros usuarios involucrados.

7. Uso limitado de los datos de Google

El uso que MCP - Gmail hace de la información recibida a través de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

En concreto: los datos obtenidos de la API de Gmail no se transfieren a terceros salvo lo estrictamente necesario para prestar la funcionalidad descripta, no se usan con fines publicitarios, no se venden y no son leídos por personas distintas del propietario de la casilla.

8. Cómo revocar el acceso

El propietario puede retirar en cualquier momento el permiso otorgado a esta aplicación desde la configuración de seguridad de su cuenta de Google, en myaccount.google.com/permissions.

Al revocarlo, la aplicación pierde de inmediato todo acceso a la casilla.

9. Conservación y eliminación

Como no se almacena contenido de correos, no hay datos que conservar ni que eliminar. El único dato persistente es el token de acceso guardado localmente, que se elimina borrando el archivo correspondiente en la computadora del propietario o revocando el permiso según el punto anterior.

10. Menores de edad

La aplicación no está dirigida a menores de edad ni recopila deliberadamente datos de personas menores de 18 años.

11. Cambios en esta política

Si la aplicación cambia su funcionamiento o los permisos que solicita, esta página se actualizará y se modificará la fecha de última actualización indicada al inicio.
